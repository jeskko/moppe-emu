# Nokia R40 (RC40 / RD40)

Status (2026-10-05): runs the original Nokia firmware of an RC40 S22G-A1,
"Cr 13.04-0" (06.08.1993, AC-2 system), with a CU43 control head or a
CU43PROG service head. With an empty battery-backed RAM it boots, shows
"Self test" and then "Service necessary / Error 6" (own subscriber
number lost), as the service manual says a radio with lost NV contents
does. With the service key fitted and PWR held at power-on it lists all
the lost-NV errors and enters the LOCAL (service) mode display, takes
digits and runs tests with OK. There is no community firmware for the
R40; hardware facts and sources are in the firmware repo's
`notes/r40.md`.

## Limits

- Tests start from an empty NV (the firmware's own cold start) and
  program it through the service mode; the NV layout found so far is in
  the firmware repo's `notes/r40.md`.
- ALPHA, the handset key, HF and F1 are not placed in the matrix, nor
  the PWR key's other roles; nothing has been checked on hardware.
- Normal mode with a subscriber number hunts for a control channel (the
  STE synthesizer steps through 403-473 MHz) and never loads the RX
  N/A; not understood yet.
- FX429 has no bit-level FFSK, no SYNC/SYNT detection and no checksums;
  no trunking control channel is simulated.
- FX803 (CCIR/DTMF) only logs its command bytes; the DS1202 does not
  tick; the RF side (RSSI, squelch, lock) is a set of constants.
- The external watchdog (IC57) and the power-off logic are not modelled.
- Instruction timing is approximate (see Model).
